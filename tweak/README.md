# LINEBridge Tweak

iOS 4.3以上／armv7向けのTheosプロジェクトです。指定した互換ゲートウェイへ接続し、サーバー証明書のSHA-256フィンガープリントを確認します。

現在のソースには、非所持の受信スタンプについてスタンプID・パッケージID・版の対応を保持する処理も含まれます。購入済みフラグやスタンプ選択一覧には追加しません。

```sh
make package
```

生成したパッケージは自分が所有する端末にだけインストールしてください。サーバーIPと証明書フィンガープリントは未設定なので、インストール後に「設定 > LINE Bridge」で入力します。
