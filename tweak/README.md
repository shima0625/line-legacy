# LINEBridge Tweak

iOS 5以上／armv7向けのTheosプロジェクトです。指定した互換ゲートウェイへ接続し、サーバー証明書のSHA-256フィンガープリントを確認します。

iOS 5対応端末はarmv7のため、`ARCHS = armv7`のままビルドしてください。armv6はiOS 4.2.1以前の端末用で、このパッケージの対象外です。

現在のソースには、非所持の受信スタンプについてスタンプID・パッケージID・版の対応を保持する処理も含まれます。購入済みフラグやスタンプ選択一覧には追加しません。

```sh
make package
```

生成したパッケージは自分が所有する端末にだけインストールしてください。サーバーIPと証明書フィンガープリントは未設定なので、インストール後に「設定 > LINE Bridge」で入力します。

## 他のLINE向けtweakとの同居

LINEの通信やセッションに手を入れる古いtweakが同じ端末に残っていると、二重にフックされて動作が重くなります。iPhone 4S (A5) では、役割の重なるtweakと同居させた状態でアプリの復帰が10秒を超え、`0x8badf00d`（ウォッチドッグ）で強制終了しました。外したところ解消しています。

LINEBridgeを入れる前に、LINE向けの古いtweakは削除してください。
