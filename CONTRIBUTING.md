# Contributing

Keep changes narrowly focused on compatibility for software and accounts you are authorized to test.

Before submitting a change:

1. Remove captured payloads and replace identifiers with synthetic fixtures.
2. Do not add proprietary binaries, decrypted executables, app assets, credentials, or private keys.
3. Compile-check Python and syntax-check JavaScript.
4. Describe device/client versions and test outcomes without publishing account data.

Changes that automate abuse, evade account controls, collect third-party data, or expose the gateway as a public relay are out of scope.
